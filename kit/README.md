- 결과 파일은 `kit/results/` 에 쌓입니다. 이 폴더는 git 이 무시하도록 되어 있고, **절대 커밋하지 않습니다.** 이 저장소는 공개입니다.
- 회사 템플릿 · 실데이터 · 실제 장표를 저장소 폴더 안에 복사해 두지 않습니다. 경로만 명령에 넘깁니다.

- M0 가 끝나면 `kit/` 폴더를 통째로 지웁니다.

## 결과 보내기 — 6줄

결과는 아래 여섯 줄만 대화에 적어 주십시오. 각 도구가 화면에 `보낼 줄:` 로 시작하는 줄을 찍으니, 그 줄에서 `보낼 줄: ` 만 빼고 옮겨 적으시면 됩니다. 칸은 공백 하나로 나눕니다.

```text
K1 <판정> <Python 판 3.x> <불러오지 못한 필수 패키지 수>
K4 <판정> <레이아웃 수> <제목+본문/그림 레이아웃 수> <이전 판과 구조가 바뀌었거나 한쪽에만 있는 레이아웃 수 · 이전 판을 안 넘겼으면 ->
K5 <판정> <복구 대화상자 0 없음 · 1 있음> <글자가 넘치거나 잘린 장 수>
K2 <판정> <그림 A · B · X> <도구 호출 O · X> <question 도구 O 선택화면 · T 글목록 · X 안함> <deck 구조 통과 0-5>
K3 <판정> <범주 맞은 수 (17문항 중)> <숫자 맞은 수 (9문항 중)> <정답 파일을 열었으면 1 · 아니면 0>
K6 <결정 N · B · H> <가장 잘한 갈래의 G2 퍼센트> <그 갈래의 G3 점수 1-5>
```

| 코드 | 뜻 |
|---|---|
| 판정 | `G` 초록 · `Y` 노랑 · `R` 빨강 · `-` 아직 안 함 |
| `-` | 아직 안 했거나 알 수 없는 칸 |
| `?` | 사람이 손으로 확인해 채울 칸. K5 는 스크립트가 `K5 ? ? ?` 로 찍으니, PowerPoint 로 파일을 열어 본 뒤 세 칸을 바꿔 적습니다 |
| K6 결정 | `N` 만들지 않는다 · `B` 만든다 (중간 · 미달 포함) · `H` 보류 (자세히는 [baseline/README.md](baseline/README.md)) |

예시입니다 (지어낸 값입니다).

```text
K1 G 3.11 0
K4 G 12 9 1
K5 Y 0 2
K2 G A O T 4
K3 Y 13 6 0
K6 B 70 3
```

- 보내는 것은 이 여섯 줄이 전부입니다. 끝에 짧은 말(예: `K1 pandas 설치 막힘`)은 몇 마디까지 붙여도 됩니다.
- 파일 이름 · 회사 이름 · 레이아웃 이름 · 오류 글은 적지 않습니다.
- 각 폴더 README 의 긴 결과 표는 사내에 보관하는 자세한 기록이며 보내지 않아도 됩니다.
