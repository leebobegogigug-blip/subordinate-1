# M0 정찰 키트

Subordinate–1 을 만들기 전에, 회사 PC 에서 되는 것과 안 되는 것을 숫자와 판정으로 알아내는 도구 모음입니다. 기획서 [docs/PLAN.md](../docs/PLAN.md) 의 08 M0 정찰(KIT-1 – KIT-6)에 해당합니다. 앱 코드가 아니라 버리는 코드입니다.

## 폴더

| 폴더 | 무엇을 재나 | 상태 |
|---|---|---|
| [env/](env/README.md) | KIT-1 환경(Python · 패키지 · COM) · KIT-4 회사 템플릿 · KIT-5 PowerPoint 열림 | 이 폴더의 README 를 따라 하세요 |
| llm/ | KIT-2 · KIT-3 사내 LLM 과 그림 판독 | 다른 작업에서 만드는 중입니다 |
| baseline/ | KIT-6 기준선 비교 | M0 뒷부분에 만듭니다 |

## 지켜 주실 것

- 결과 파일은 `kit/results/` 에 쌓입니다. 이 폴더는 git 이 무시하도록 되어 있고, **절대 커밋하지 않습니다.** 이 저장소는 공개입니다.
- 회사 템플릿 · 실데이터 · 실제 장표를 저장소 폴더 안에 복사해 두지 않습니다. 경로만 명령에 넘깁니다.
- 결과를 알려 주실 때는 **숫자와 판정만** 적습니다. 파일 내용, 파일 이름, 템플릿의 레이아웃 이름 · 마스터 이름은 적지 않습니다. `env/README.md` 마지막의 표를 채워 대화에 붙여 넣으시면 됩니다.
- M0 가 끝나면 `kit/` 폴더를 통째로 지웁니다.
